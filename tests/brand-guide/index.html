01 // Identity

Every surface looks like an instrument on a military spacecraft — precise, powered, engineered, never decorated. Reference points: Halo HUD, Elite Dangerous, 2001. The test for any asset: could this plausibly be a readout on a spacecraft bridge?

02 // Color System

Four palettes, five fixed roles, three intensities each. Dark dominates (~85% of any screen); color is an accent that earns attention. Same roles + same ratios = sibling games, different palettes.

03 // Typography

Three faces, seven roles, zero per-game decisions. Only body is sentence case; tracking widens as size shrinks. Never mix roles within a line.

04 // Iconography

Instruments, not primitives — gradient silhouette, glowing outline, dark internal detail, one semantic highlight. Recognizable from silhouette at 16px.

05 // Components

Clipped corners, thin lines, selective glow. Instrument detail is mandatory: gauges get segments and scale ticks, radar gets bearing marks and a phosphor sweep.
